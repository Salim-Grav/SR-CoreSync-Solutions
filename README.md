## 🌐 Multilingual Architecture (1:1 Complete Parity)

The platform is engineered with a bespoke triple-language ecosystem:
- 🇸🇦 **Arabic (العربية)**: Default root [`index.html`](./index.html) - RTL layout, tailored typography using Alexandria & Plus Jakarta Sans.
- 🇬🇧 **English**: [`en/index.html`](./en/index.html) - LTR layout, European enterprise terminology.
- 🇳🇱 **Dutch (Nederlands)**: [`nl/index.html`](./nl/index.html) - LTR layout, compliant with Dutch fiscal & EU GDPR requirements.
